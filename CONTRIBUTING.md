# Contributing

Thanks for looking at the code. Fixes, tests and docs are all welcome, and first-time contributors are too.

## Before you start

Open an issue first for anything bigger than a typo, so we agree on the approach before you spend time on it. Small fixes can go straight to a pull request.

## Pull requests

Keep each pull request to one change. Add or update a test when you change behavior, and say in the description how you checked it. I review every pull request and reply in writing.

## Where to begin

Issues labeled good first issue or help wanted are small and scoped. Leave a comment before you start, so two people don't work on the same thing.
