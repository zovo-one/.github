# Getting help

Bug reports and questions go in the issues of the repository you're using. Include the version, the steps that cause the problem and what you expected to happen.

Need an engineer for your own product or AI agent? Send a written brief at [axdale.com](https://www.axdale.com/?utm_source=github&utm_medium=support&utm_campaign=hire).

If the project helps you, [sponsoring on GitHub](https://github.com/sponsors/theluckystrike) keeps it maintained.
